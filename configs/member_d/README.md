## Current A/C threshold handoff

`fusion.json` remains the intended production fusion template once C publishes
source-record-complete competition features.

Until then, use:

- `fusion_provisional_minimal.json` — diagnostic-only fusion using tree score,
  neural logit and source indicators. It intentionally excludes all
  `competing_s1_*` / `is_top_competing_s1` fields.
- `gate_audit.json` — the standard D cutoff/budget audit values. Production
  pair counts are projections, not guarantees.

Run the current safe threshold integration rehearsal with:

```bash
bash scripts/run_member_d_threshold_rehearsal.sh
```

The rehearsal:
1. validates A's checkpoint card, exposure table, full threshold neural scores
   and routed neural scores;
2. refuses C gates carrying truth-derived fields such as
   `is_injected_positive`;
3. evaluates gate/cutoff recall on `threshold_queries.tsv` only;
4. creates a separate keyed label artifact;
5. drops incomplete source-group competition features;
6. fits provisional fusion/calibration and sweeps the decoder on D's `selection`
   partition only.

All rehearsal outputs are marked diagnostic-only / selection-ineligible. They
must be rerun with C's source-complete production artifacts before the final
fusion/calibration/decoder freeze.

Before production runs, fill the runtime budget with measured A/B/C throughput
and memory values. Do not replace unknown values with fabricated model-quality
metrics.
